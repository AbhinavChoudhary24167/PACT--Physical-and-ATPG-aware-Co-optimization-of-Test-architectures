# Saved H8 diagnostic evidence

The supplied diagnostic records classify the saved corpus as `PACT_H8_ROOT_CAUSE_IDENTIFIED`: omitted depth-limited spatial regions and candidate ground-capacitance errors explain hotspot-ordering failures. Ordered substitutions around a nonlinear maximum do not uniquely allocate causal effects. No replacement model or out-of-corpus prediction is validated.

The original analysis covers 28 architectures and 37 problematic pairs. Compact retained evidence includes [analysis_summary.json](analysis_summary.json), [problem_pairs.csv](problem_pairs.csv), [pair_summary.csv](pair_summary.csv), [mechanism_summary.csv](mechanism_summary.csv), [cross_design.csv](cross_design.csv) and the source/input hash manifests. The reported diagnosis predates cleanup; its original timestamp/revision/source hashes remain in those receipts.

Diagnostic source is in `scripts/pact_h8_{rootcause,export,report}.py` and `src/pact/analysis/h8_rootcause.py`. Rebuilding the decomposition requires the recorded routed databases, cycle/net counts and extracted C inputs; see [reproducibility](../../docs/reproducibility.md). Raw per-net dumps, build workspaces and local logs are excluded from Git. [Research status](../../docs/research_status.md) describes the current claim boundary and unresolved fault identities.
