The new [witness](B3R_witness/witness.json) executes the unchanged binary on frozen s5378/K=2 and reproduces `Cannot faithfully trace native SI/SO connectivity`. Its [saved-ODB observation](B3R_witness/observation.json) and generated Verilog preserve the failure. This report precedes source modification.

`src/dft/src/stitch/ScanStitch.cpp`, `ScanStitch::Stitch`, selects the fixed scan-input driver and scan-output load and wires the initial chain. `Dft::writeToOdb` in `src/dft/src/Dft.cpp` saves these actual BTerm/ITerm endpoints and per-cell access pins in `dbScanChain`/`dbScanInst`. `dbScanList::add` prepends entries, so logical scan order is the reverse of list iteration.

`Dft::scanOpt` groups chains by clock domain, adapts existing scan instances with `OdbScanCellAdapter`, runs `KMeansClusters` (100 iterations, unchanged effective bit cap), reassigns membership, and invokes `RestitchChain`. Per-chain optimization subsequently reverses list iteration, runs `OptimizeScanWirelength` in `src/dft/src/optimizer/Opt.cpp` (NN, directed 2-Opt, direction-preserving 3-Opt, 50 candidates), and passes that final vector to `RestitchChain`. External endpoints are annotations on the chain, not vertices in the local optimizer cost. Changing order or reversing a segment does not authorize changing the fixed endpoint identity.

`RestitchChain` derives the head from `cells.front()` and tail from `cells.back()`. It connects the new head SI to the original SI net and each successor SI to its predecessor's existing SO/Q net. ODB `connect` disconnects that load from its prior net. The final block instead calls `chain->setScanOut(last_so)`: this replaces the fixed output-load annotation with the tail's output ITerm, while moving no output port. The preclustering call already loses the endpoint identity; the final call repeats that substitution. A misleading comment treats the endpoint load as functional Q, although initial stitching stores an output BTerm or input ITerm load. Functional Q fanout is preserved by moving only the endpoint load, leaving Q and other sinks on their nets.

Actual failing topology: chain 0 contains 90 distinct FFs from `U_n1525gat` through `U_n2510gat`, terminating on `n2510gat`; chain 1 contains 89 from `U_n2347gat` through `U_n707gat`, terminating on `n707gat`. Fixed SO ports remain on `n2502gat` and `n2121gat`, interior nets in chain 0. The endpoint failure is physical, present in both ODB and serialized Verilog; it is not an adapter assumption.

A second defect affects representation agreement: final per-chain optimization restitches physical edges without updating `dbScanList` order. Its membership is correct, but its normalized order remains the pre-optimization order. Updating endpoint metadata alone cannot qualify this output.

Required invariant: fixed SI → final optimized head → every final optimized successor exactly once → final optimized tail → corresponding fixed SO, with reverse-stored native scan-list order representing the identical path. No functional driver, master, placement, orientation, D/CK connection, or unrelated functional sink may change.
