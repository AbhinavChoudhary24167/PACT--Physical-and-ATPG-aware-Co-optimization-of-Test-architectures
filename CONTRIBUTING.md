# Contributing

Follow [environment](docs/reproduction/environment.md) for installation/tests; run the complete harness on Linux/WSL. Model changes need exact-reference, rollback, topology/identity and replay validation. Documentation changes need path/link checks.

Keep source, schemas/configs, small fixtures, frozen orders, compact tables, provenance and negative conclusions in Git. Place environments, caches, builds and bulk tool output under explicit ignored scratch/archive roots. Follow [retention policy](archives/README.md) before discarding evidence.

Separate predictions, implemented measurements and practical impact. Preserve failed/interrupted outcomes, registration settings and original hashes. Do not modify sealed receipts to disguise a new run. Follow upstream tools' licensing/formatting/contribution rules for their patches.

Submit focused branches/PRs with the problem, resulting behavior, validation and limits. Public history rewrites require a separate deliberate operation.
