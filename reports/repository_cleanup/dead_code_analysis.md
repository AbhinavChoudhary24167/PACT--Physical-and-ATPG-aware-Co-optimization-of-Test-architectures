# Source retention analysis

Current optimizer, stateful, integration and Stage-B modules remain canonical. Phase-named metric/scan/topology helpers remain because current adapters or their contract tests import them. Old H_eff8 Optimizer v1/v2/v2.1/v2.2/v2.3 implementations, runners and paired tests had no current product import outside that retired subsystem; historical freeze scripts referenced their paths and are removed. Script closure includes Python imports and literal .py filenames from current runners and retained tests; historical top-level campaigns outside it are removed. This is a conservative call-relationship analysis, not a claim that every retained helper is independently public. No optimizer parameters or scientific objective were changed.

## Final dependency corrections

Retained `phase0b_analyze.py` and `phase0b_stage_seed_audit.py` because current runners import them as scripts.* modules. Phase-1's exact selection function and Phase-2A's correlations/weighted_corr remain byte-equivalent function bodies; their obsolete campaign launch/report functions and Phase-2A freezer were removed. Historical funnel tests requiring all 375 raw route directories were retired; shared funnel helpers remain in the Phase-0D qualification dependency. Essential real topology fixtures were restored independently of any raw campaign tree.

The supplied active H8 diagnostic source and regression are incorporated with compact saved summaries. Large untracked diagnostic dumps and upstream contribution workspaces remain local and ignored, outside the published implementation. Source history remains in Git; copied source snapshots were deleted.
