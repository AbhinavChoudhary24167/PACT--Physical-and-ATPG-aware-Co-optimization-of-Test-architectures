# Phase-0B reproducible campaign

This campaign adds evidence under `artifacts/{raw,derived,manifests}/phase0b/` and does not regenerate the frozen Phase-0 files. The pre-edit Git commit, original evidence checksums, tool versions, and actual WSL package inventory are in the two Phase-0B manifest JSON files.

The pinned research runtime used here is WSL with OpenROAD, Yosys, and ORFS under `/root/pact-deps/OpenROAD-flow-scripts/flow`, FAN_ATPG under `/root/pact-deps/FAN_ATPG`, and Python at `/root/pact-deps/pact-venv/bin/python`. The explicit s15850 BUF_X3→BUF_X4 input translation is prepared by `scripts/phase0b_prepare_s15850.py`. From the repository root, set `PYTHONPATH=src` and run `scripts/phase0b_pipeline.py --design DESIGN --seeds 11 13 17 19 23` for each of `s5378`, `s9234`, and `s15850`. Each external stage is timeout-bounded and archives command, stdout, stderr, exit, timestamps, timeout, and output hashes. Valid completed stages resume; invalid previous attempts are moved to `attempt_NNN` before retry.

The physical seed method and its limitation are frozen in `config/phase0b_seed_method.json`. Global placement is common to the design; a seed perturbs and legalizes it before any scan intervention. Every method within the design×seed pair starts from that same frozen placement. `GRT_SEED` is also passed into ORFS global routing. `scripts/phase0b_stage_seed_audit.py` checks the actual saved command arguments, and `scripts/phase0b_qualify_seeds.py` checks distinct placed component coordinates across the full predeclared seed set. Ordering seeds are separate.

`scripts/phase0b_analyze.py` builds all Pareto, effect-size, replication, and learning-gate fields from qualified pairs. `scripts/phase0b_figures.py` rebuilds 24 per-design figures plus one aggregate. `scripts/phase0b_report.py` renders the final decision report, and `scripts/phase0b_verify_report.py --require-complete` checks all predeclared pairs, links, classification, figures, and all 447 frozen Phase-0 evidence hashes. Run the unit suite with `PYTHONPATH=src:. /root/pact-deps/pact-venv/bin/python -m pytest -q tests/unit`.

OpenROAD-native B1 requires the isolated `test_cell` Liberty annotation and the prescan equivalent recorded in the DFT evidence. B0 always means the supplied FAN order. OpenDB scan-edge extraction qualifies exact scan-only length only on exclusively Q→SI two-terminal nets; otherwise the predeclared scan HPWL proxy is primary. Buffered scan edges and mixed functional branches are explicit in `scan_route_metrics.json`. The saved `plan.pre_edge_distribution.json` and `scan_route_metrics.pre_buffered.json` files preserve earlier Phase-0B records corrected during the metric audit.
